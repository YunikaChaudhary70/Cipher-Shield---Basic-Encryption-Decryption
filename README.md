# Cipher-Shield---Basic-Encryption-Decryption
Symmetric encryption and decryption tool using Caesar Cipher. Built for DecodeLabs Cybersecurity Internship.
## What it does
- Encrypts plaintext to ciphertext using shift key
- Decrypts ciphertext back to original text
- Handles uppercase, lowercase, spaces and punctuation

## Tech Stack
- **Language**: Python 3.x
- **Concepts**: Cryptography, ASCII, Modular Arithmetic `% 26`

## How it works
Caesar Cipher shifts each letter by `n` positions.
- Encryption: `E_n(x) = (x + n) % 26`
- Decryption: `D_n(x) = (x - n) % 26`
